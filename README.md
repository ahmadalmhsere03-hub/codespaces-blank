# GalaxyTV

تطبيق Android أصلي مطوّر باستخدام Kotlin وJetpack Compose، ويدعم Android TV وGoogle TV وأجهزة Android Box.

## التوافق

- Android 7.0 أو أحدث (API 24 فأعلى).
- Android TV وGoogle TV، مع دعم التشغيل الأفقي والتنقل بجهاز التحكم.
- يعرض التطبيق صورة `logo-login` عند بدء التشغيل، ثم يتحقق من كود التفعيل المحفوظ.
- اللغة الافتراضية هي الإنجليزية، ويمكن تغييرها إلى العربية أو الفرنسية من الإعدادات.
- يعرض قسما Live وSports الباقات والقنوات في قائمتين منفصلتين للمحتوى العربي والإنجليزي.
- يجلب قسما Movies وSeries تصنيفاتهما من الخادم، ويعرض قسما Kids وRamadan التصنيفات المطابقة من الأفلام والمسلسلات.
- يشغّل القنوات والأفلام والحلقات باستخدام Media3 ExoPlayer.

## التشغيل والبناء

افتح المشروع في Android Studio وثبّت Android SDK Platform 36 عند الطلب، ثم شغّل إعداد `app` على هاتف أو محاكي Android TV.

```bash
./gradlew :app:assembleDebug
```

سيُنشأ APK التجريبي في `app/build/outputs/apk/debug/app-debug.apk`.

تُحمّل القنوات والأفلام والمسلسلات من واجهة API الخاصة بالخادم. يعتمد ظهور محتوى Kids وRamadan على وجود تصنيفات مناسبة ضمن بياناته.

تُضبط بيانات الاتصال بالخادم في الملف المحلي `app/server.properties`، وهو مستثنى من Git. يرسل التطبيق الطلب بعد تطبيق XOR وترميزه بـBase64، ثم يفك تشفير رد الخادم الثنائي بتطبيق XOR قبل قراءة JSON. يستخدم البروتوكول الحالي HTTP وXOR، وهما لا يوفران حماية مناسبة على الشبكات العامة؛ يُنصح بنقل الخدمة إلى HTTPS.

يحاول التطبيق قراءة عنوان MAC على Android 7 إلى 9، ويرسل قيمة فارغة على Android 10 فأحدث، حيث يقيّد النظام الوصول إليه. ويرسل Android ID في الحقل `sn`؛ لذلك يجب أن يقبل الخادم هذا المعرّف على أجهزة Android Box الحديثة.
